Hybrid Cache Manager#

class HybridCacheManager#

Top-level cache manager for hybrid Attention + Mamba architectures.

Routes cache access by absolute decoder-layer index to the appropriate sub-manager (KVCacheManager for attention layers, MambaCacheManager for recurrent layers). Owns the shared device KV cache lengths tensor and provides unified compaction, prompt cache capture / restore, and batch management APIs that span both sub-managers.

Exchange the KV lengths of two execution rows. Self-inverse; the device counterpart of DecodingInferenceContext::swapExecutionRows, which a batch-one projection pairs it with so the projected row runs as row zero while every other row’s length is kept where it belongs.

Throws:

void appendSequence(int32_t committedLength, cudaStream_t stream)#

Append one sequence to the active batch, as the last execution row, with the KV length it already holds (committedLength: a reused prefix, or zero). The runtime session reserves the row with the sequence’s other reservations so the batch here follows the context’s from the seat on, prefilled or not. Strong exception guarantee: a throw leaves the batch as it was.

Throws:

std::runtime_error – when the batch is full or the device update cannot be enqueued.
