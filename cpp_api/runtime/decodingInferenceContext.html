struct SlotSeed#

Per-request execution context shared by runtime and decoding strategies.

Holds request-local sequence metadata, sampling parameters, multimodal embedding references, streaming state, and batch-eviction bookkeeping.

Everything a newly admitted sequence brings when it joins a batch that is already running.

Only what is per-slot belongs here: the prompt, delivery, and the request’s own decoding settings (sampling, seed, generate budget, logprobs width). The few settings that remain batch-wide – the LoRA adapter, thinking mode – live on the context itself; whether the arriving request agrees with those is the scheduler’s admission decision, made before a seed is ever built.

Multimodal admission payload.

Encoder outputs staged by the runtime’s admission preprocess, consumed by the seated prefill within the same generation boundary. The tensor references point at the multimodal runners’ output buffers, which stay untouched until the next admission’s preprocess – at most one admission is pending at a time, so the seated prefill is always the next consumer. The media identity travels too, so the context cache can tell a media prefix from a text prefix over the same ids: each image as the content identity the admission preprocess computed (one entry per image, in prompt order), audio as its raw buffers, which the cache hashes.

int32_t appendSlot(SlotSeed seed, SequenceIdentity identity)#

Add one sequence to the batch. Returns the new execution-row index.

The reverse of eviction, and bound by the same invariant: every per-slot vector grows by exactly one entry, so the batch stays rectangular and a later compaction moves every slot’s state together. Slots already in flight are not touched – their tokens, progress and delivery state stay where they are.

The batch may be empty: a context initialized for zero sequences grows its first slot here exactly as it grows its tenth. Nothing per-slot is inherited from a neighbour; the logprobs accumulator is sized from the seed’s own budget and width.

Parameters:

identity – Stable request identity and an already-acquired physical resident row.

Throws:

std::runtime_error – if the prompt is empty, the seed carries no generate budget or an out-of-range logprobs width or top-k, either identity is invalid or already live, or the seed’s channel is attached elsewhere. Nothing is modified on any throwing path; the caller retains ownership of identity.resident.

void swapExecutionRows(int32_t rowA, int32_t rowB)#

Exchange the transient execution-row view of two logical sequences. Self-inverse.

This is used to present one admitted sequence as execution row zero for a batch-one prefill. ResidentRef travels with the logical sequence, so ragged state_indices still name its stable physical KV/recurrent row; no resident state or page-table row is exchanged.

Throws:

std::runtime_error – if either slot is out of range. A self-swap is a no-op.

Initialize request-local vectors and scalar fields for a batch of batchSize sequences, each holding one freshly acquired resident row.

batchSize may be zero: the context then holds no sequence and every later one arrives through appendSlot(). residentCapacity bounds the resident rows over the context’s life; zero means “exactly the initial batch”, so an empty batch needs it explicit.

Parameters:

  • batchSize – Active batch size

  • maxGenLength – Maximum generation length

  • visual – Optional visual embeddings

  • deepstackFeatures – Deepstack features for Qwen3-VL

  • loraName – LoRA weights name used by this request

  • cudaStream – CUDA stream for operations

  • residentCapacity – Resident rows the slot pool hands out, or 0 for batchSize

DecodingInferenceContext()#

ctor / move ops / dtor are out-of-line (defined in the .cpp) because layerDebugger is a unique_ptr to the incomplete type LayerDebugger: a defaulted special member in the header would instantiate the member’s destructor against the incomplete type in every translation unit (e.g. unit tests that only forward-declare LayerDebugger). Move ops are declared because the user-declared destructor otherwise suppresses the implicit move, and the context is returned by value in places. The struct stays non-copyable via the unique_ptr member.

Per-slot guided-decoding gate: 1 once the reasoning block is over. Deliberately not thinkingDone, which also flips when the first generated token is not a thinking marker – that token is answer content, so treating it as “reasoning over” would let it past the mask and out of the matcher’s prefix.
