struct MultiStageConfig#

The topology, as data.

A MultiStageConfig is the whole topology: which stages exist, what each one emits, and which port feeds which input. It is parsed from multistage_config.json and is pure data – no callables, and no path that escapes the config root.

Nothing here knows about a model family. A family is a set of values in this structure, not a branch in the code.

Structural checks that must hold before anything is constructed.

Every rule here is one a layering bug could otherwise turn into a runtime surprise. This is the authority at load; the Python builder runs its own, separate preflight before it writes a config.

Parameters:

  • config – Parsed topology.

  • configRoot – Used only to reject an artifact that escapes the root. Pass an empty string to skip the filesystem check.

Throws:

std::runtime_error – naming the stage, the input and the rule.
