Cute Dsl Fmhav2 Runner#

class CuteDslFMHAV2Runner#

Runner for the CuTe DSL FMHA-v2 kernels.

Dense LLM kernels consume separate BSND Q/K/V tensors, while native-paged LLM kernels consume BSND or packed Q/O and the Edge-LLM NHD paged KV pool. Vision blocks support both dense separate Q/K/V and packed Q/O with paged KV; padding uses dense Q/K/V and ViT uses packed separate Q/K/V. The runner remains separate from CuteDslFMHARunner because the optimized SM100/101/103/110 family has a distinct ABI.

Runs FP16 causal or sliding-causal attention directly against an FP16 NHD paged KV pool.

Parameters:

  • skipSoftmaxScaleTable – Skip-softmax (BLASST) scale table, device Int32 of flattened (seqlen_bin, S) pairs with bins ascending; a flat S is the one-row table {0, S}. Causal, non-sliding only: per sequence the kernel floor-looks-up S by its KV length (cuKVSeqLens, which is never padded here) and skips the P*V GEMM of KV tiles whose contribution is below lambda = S / seqlen_kv of the running max — approximate. Sequences below the first bin or with S >= seqlen_kv run dense.

  • skipSoftmaxScaleTableLen – Element count of the table; 0 (the default) runs every sequence dense.

bool runPagedRagged(PagedRaggedParams const &inputs)#

Runs causal, sliding-causal, or vision-block attention over packed Q/O and FP16 NHD paged KV.

cuQSeqLens and cuKVSeqLens are monotonic prefix arrays of length batchSize + 1. cuQSeqLens starts at zero and ends at totalQSeqLen. cuKVSeqLens contains the complete logical KV history, including prior cached tokens. maxQSeqLen is the maximum adjacent difference in cuQSeqLens, not the packed buffer allocation capacity. attentionSinks optionally points to device-resident FP32 sink logits indexed by query head; nullptr disables sinks. bidirectionalBlockBegin and bidirectionalBlockEnd optionally contain inclusive, sequence-relative KV intervals, indexed by packed query row [totalQSeqLen]. Text rows use the empty interval [-1, -2]. Vision blocks must be contiguous and contain the query at KV position (kvLength - qLength + queryRow).
