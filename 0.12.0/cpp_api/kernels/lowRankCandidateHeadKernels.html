Low Rank Candidate Head Kernels#

class LowRankCandidateHeadRunner#

Fused low-rank candidate head: K0 s = fp16(hidden downProj^T); for passes above 8 rows, or every pass when upProj fits in L2, a pilot bound per row from the maxima of sampled upProj tiles; K1 tensor-core low-rank scores of every vocab row with a per-CTA streaming top-Kc (upProj read once per pass, scores never written); K2 merge of the per-CTA lists, lmHead gather-dot, sort by (exact logit desc, id asc), then log_softmax over the Kc exact logits.

Public Functions

LowRankCandidateHeadRunner(
LowRankCandidateHeadShape shape,
int32_t maxRows,
cudaDeviceProp const &prop
)#

Picks the per-device configuration (rows per pass, tile, stages, survivor capacity, grid) from prop’s SM version, SM count and shared-memory limit, and sets the kernel attributes on the current device, whose occupancy queries size the grids (prop normally describes the current device). Throws for unsupported shapes or devices (SM < 80).

size_t workspaceBytes() const noexcept#
void run(
rt::Tensor const &hidden,
rt::Tensor const &downProj,
rt::Tensor const &upProj,
rt::Tensor const &lmHead,
rt::Tensor &candidateIds,
rt::Tensor &candidateLogProbs,
void *workspace,
cudaStream_t stream
) const#

hidden [R, H] fp16 with 0 <= R <= maxRows; downProj [r, H], upProj [V, r], lmHead [V, H] fp16, all 16-byte aligned. Writes candidateIds [R, Kc] int32 and candidateLogProbs [R, Kc] fp32 sorted by (logit desc, id asc). workspace: workspaceBytes() of scratch; no state persists across calls. No allocation and no host sync, so the call can be captured in a CUDA graph.

The smallest workspace that any configuration withinWorkspace may choose needs on this device; results do not depend on the configuration, only the speed does.

static LowRankCandidateHeadRunner withinWorkspace(
LowRankCandidateHeadShape shape,
int32_t maxRows,
cudaDeviceProp const &prop,

)#

The device’s preferred runner if its workspace fits workspaceLimit, else the first of a fixed sequence of smaller configurations (fewer pilot witnesses, no pilot, smaller survivor buffers, fewer CTAs per pass) that fits. Throws when none does, that is below minimumWorkspaceBytes.
