Code Predictor#

class CodePredictor#

Residual codebook prediction, one engine behind the talker.

One frame is one sequence: the engine runs a two-row prefill and then either numRvqLayers - 1 decode steps or, with speculation on, draft/verify rounds. The KV cache holds a single frame, so the talker resets it at the start of every frame and no state crosses a frame boundary.

This owns its engine, its weights and every workspace it touches. Two tensors belong to the talker’s codec vocabulary and are only borrowed: the code_0 embedding table and the per-frame codec-hidden buffer whose middle rows are filled here for the talker’s residual. Both arrive in Binding.

The small_to_mtp projection needs the CuTe DSL GEMM module, which the talker loads before preallocate() and unloads on destruction.

Publish one step’s token-major layout to the engine’s ragged bindings.

Every execute() reads the offsets, past lengths and state indices this writes; they are not step-invariant, so binding them once per prepare() leaves the attention kernels addressing whatever the previous step left behind. The talker steps its own engine through this too.
