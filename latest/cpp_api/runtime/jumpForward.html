Jump Forward#

class JumpForwardPlanner#

Turns a grammar-forced string into tokens that can be appended without a forward pass.

The forced text is re-encoded together with the window, the most recent tokens of the sequence, so the result is the tokenizer’s own split of the joined text rather than the forced text tokenized on its own. Window tokens at the end that the re-encoding changes are rolled back and replaced; a change to any token before them skips the jump, because those are emitted or have KV.

A tokenizer that prepends a word marker (Tokenizer::prependsSpaceMarker) only reproduces a window that starts at a word boundary, so the caller must widen the window to one; a window text that does not start with a space is skipped.

The last planned token is handed back when another vocabulary token extends its piece and the plan does not complete the grammar: the text after it is not known yet, and a canonical tokenization may merge it with what follows.

The grammar state is left unchanged.

class HostDraftTree#

A verify tree on the host at the grafting width: each slot’s draft nodes first, then the forced nodes the tree walk grafts under them. The rows are pinned, so a round uploads the batch with one copy per array.

A node’s mask row is its ancestors-or-self set and its depth the number of ancestors the tree holds, derived from its parent the way buildSpecVerificationTree derives them: a node whose parent is missing hangs off nothing. Nodes follow their parents.

Whole-batch views for the upload: [maxBatchSize, width], [maxBatchSize, width, width], [maxBatchSize].

class JumpForwardCoordinator#

The decoder-independent part of a jump: the gate, the plan, and the token-list, logprob and statistics bookkeeping of applying forced tokens to a slot.

A plan whose rollbackCount is 1 replaces the slot’s sampled token, so its tokens are fed to the grammar from the state before that token; otherwise from the current state.

Graft forced chains into one slot’s draft tree before it is verified.

Walks the draft nodes in index order and feeds each node’s root path to the grammar; where the grammar then forces text, the text is planned behind the node and grafted under it, reusing draft children that already carry it. Skipped with their subtrees: a node the grammar refuses or terminates at, and a node beside a forced sibling, which acceptance never reaches. A node already on a chain is not planned again. A plan that would respell the node itself is refused and counted. The matcher ends where it started.

Parameters:

tree – The slot’s draft tree, loaded; receives the grafted nodes

Returns:

Chains grafted

int32_t planDraftChain(
DecodingInferenceContext &context,
int32_t slot,
HostDraftTree &tree,
TreeWalkLimits const &limits
)#

Graft forced chains into a slot’s draft chain before it is verified; the result stays a chain.

Feeds the chain to the grammar from the root and plans the text the grammar forces after each node. A plan the draft after the node already spells flags those nodes forced and the walk goes on. The first plan the draft does not spell ends the walk. If it has at least as many tokens as the draft nodes it departs from that the grammar accepts in a row, it keeps the draft nodes that match it and replaces the rest of the draft with its remaining tokens; otherwise the draft stays whole and the plan is counted as draft_longer. A node on a chain is not planned again. The walk ends at a node the grammar refuses or terminates at. A plan that would respell the node itself is refused and counted. The matcher ends where it started.

Parameters:

tree – The slot’s draft chain, loaded; receives the grafted nodes

Returns:

Chains grafted

class SpecJumpGrafter#

The grafting layer of a speculative decoder’s jump-forward round: grafts forced chains into the drafted verify input on the host, uploads the result, and accounts the forced tokens on the accepted paths.

A grafting round verifies jumpWidth rows per slot: the slot’s draft, the nodes grafted into it, then padding; a slot without a chain keeps its draft. Its accept step takes the forced flags and node counts held here, and a tree’s verify descriptors are prepared from the mask held here.

Per round: walk; after kGrafted, upload, verify and accept at the jump width, pass forcedPath to appendAcceptedTokens, collect logprobs, then account.
